### Top 5 quick wins
1. **Make quote items go through the verifier** (`verify.py:244`). Removing the skip closes the biggest gap in the "answer keys are checked" promise.
2. **Build a route when there is no outline** (`session.py:616`). Courses with only slides or only past papers can start Standard study instead of being told everything is mastered.
3. **Guard the built-in PDF reader** (`pdftext.py:253,389`). A size check plus a one-character octal fix remove a crash and a memory blow-up.
4. **Fix quiz timestamps** (`mimir-quiz/SKILL.md:27`). ISO `started:` plus `ended:` puts quiz time into the cram bill.
5. **Write the frustration-override rule once** (`mimir-core-rules:51`, `session.md:64`). Three files disagree today and quiz ignores it.

Close runners-up, all trivial: the term-order check (#15), the marketplace description (#24), removing the dead third question (#23), and the `mimir-help` flag (#13).
