A DFA for binary numbers divisible by 3

The machine reads a binary number from the most significant bit. State \(q_r\) means "the bits read so far have value \(\equiv r \pmod 3\)". Reading bit \(b\) in state \(q_r\) moves to \(q_{(2r+b) \bmod 3}\).

  1. Start in \(q_0\) (value 0).

  2. Read 1: \(q_0 \to q_1\) (value 1).

  3. Read 1: \(q_1 \to q_0\) (value 3).

  4. Read 0: \(q_0 \to q_0\) (value 6).

  5. Input finished in \(q_0\), an accepting state: 110 is accepted, and \(6 = 2 \cdot 3\) is divisible by 3.
