Find the amplitude, period and phase shift of \( f(x) = 3\sin\left(2x - \frac{\pi}{2}\right) \), then sketch one period.

  1. Write \(f\) in the form \(A\sin\big(B(x - C)\big)\):

    \[ \begin{aligned} f(x) &= 3\sin\left(2x - \frac{\pi}{2}\right) \\ &= 3\sin\left(2\left(x - \frac{\pi}{4}\right)\right) \end{aligned} \]

    so \(A = 3\), \(B = 2\), \(C = \frac{\pi}{4}\).

  2. Amplitude: \( |A| = 3 \).

  3. Period:

    \[ T = \frac{2\pi}{B} = \frac{2\pi}{2} = \pi \]

  4. Phase shift: \( C = \frac{\pi}{4} \), so the graph is shifted \( \frac{\pi}{4} \) to the right.

  5. Key points of one period, from \(x = \frac{\pi}{4}\) to \(x = \frac{5\pi}{4}\):

    \(x\)\(\frac{\pi}{4}\)\(\frac{\pi}{2}\)\(\frac{3\pi}{4}\)\(\pi\)\(\frac{5\pi}{4}\)
    \(f(x)\)\(0\)\(3\)\(0\)\(-3\)\(0\)

  6. Sketch of one period, with the five key points marked.

    AnswerAmplitude 3, period \(\pi\), phase shift \(\frac{\pi}{4}\) to the right.
